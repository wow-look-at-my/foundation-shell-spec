# Foundation Shell Specification

This directory contains the exhaustive specification for Foundation Shell.

## Files

- `lexer.md` - Lexical analysis and tokenization rules
- `parser.md` - Parsing rules and AST structure
- `expansion.md` - Variable, tilde, and command substitution expansion
- `execution.md` - Command execution and pipeline semantics
- `operators.md` - Operators (|, &&, ||, ;) and their precedence
- `quoting.md` - Quote handling (', ", `) with depth tracking
- `redirection.md` - I/O redirection rules
- `diagnostics.md` - Error messages and diagnostic output format
- `highlighting.md` - Syntax highlighting semantic types and themes
